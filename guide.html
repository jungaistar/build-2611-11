사용법

수기 일보를 엑셀로 옮기면 월간 설비 운영실적이 나옵니다

양식 받기 → 수기 일보 옮겨 적기 → 올리기 → 대시보드 확인 → 보고서 · 엑셀 순서로 진행합니다. 계산은 전부 이 브라우저 안에서 끝나고 파일은 어디로도 올라가지 않습니다.

1. 입력 양식

「빈 입력 양식 내려받기」를 누르면 비가동일보 시트와 범례 시트가 든 엑셀을 받습니다. 수기 생산작업일보를 한 줄에 한 구간씩 옮겨 적으세요.

설비설비군작업자날짜근무구분코드시작종료소요(분)내용
NC-012026-10-05주간비가동A09:1010:0050제관품 입고 대기
비가동C13:2013:5030지그 교체
용접로봇-012026-10-05주간비가동D14:0014:3030티칭 수정
  • 설비 · 날짜가 윗줄과 같으면 비워 두어도 됩니다.
  • 설비군 칸은 선택입니다(가공 / 용접). 비우면 설비 이름으로 정합니다 — 로봇 · 용접 · ABB · KOBE · 야스카와 또는 용접 라인 이름 MAIN · BOOM · TRACK · SUB · CHASSIS · ARM · BUCKET · BLADE(「N호기」 유무 · 대소문자 · 띄어쓰기 무관)가 들어 있으면 용접설비, NC · CNC · MCT · 밀링 · 호리젠탈 · 머시닝 · 선반이 들어 있으면 가공설비, 그 밖은 가공설비입니다. 「NC 용접기」처럼 둘 다 들어 있으면 확인 필요로 표시하고 가공으로 세니 「기준 설정 → 설비군」에서 골라 주세요. 범례 시트 아래의 기획자 설비 목록(2026-11) 이름을 그대로 적으면 저절로 맞습니다.
  • 비가동만 적어도 됩니다. 그러면 가동 = 계획 − 비가동으로 계산하고 계산 표시를 붙입니다.
  • 가동 줄까지 빠짐없이 적으면 빈 시간(누락)과 겹친 구간을 찾아 「확인할 것」에 올립니다.
  • 소요(분)를 적으면 시작~종료로 계산한 값과 대조합니다. 다르면 계산한 값을 쓰고 알려 줍니다.
  • 엑셀의 드롭다운 목록은 넣지 않았습니다. 사유 코드는 범례 시트를 보고 적으세요.

2. 읽을 수 있는 자료

올린 파일의 시트마다 머리글 낱말을 보고 형식을 알아서 고릅니다. 틀리면 시트 옆 목록에서 바꾸세요.

작업자별 작업일보번호 · 구분 · 코드 · 항목 · 시작시간 · 종료시간 · 소요(분)작업자마다 시트, 날짜 블록 위 줄의 날짜, 엑셀 시간값

수리 · 비가동 이력시작일자 · 완료일자 · 고장부위「10.01 11:00 ~ 11:30」 구간 글자, 비가동 총시간 대조, 비용

설비 가동률 시트의 「비가동 내역」에는 분이 없습니다. 한 칸에 사유가 여럿이면 그날 비가동 시간을 사유 수로 똑같이 나누고 추정 표시를 붙입니다. 가동 시간 · 비가동 시간은 분 단위로 봅니다.

3. 기준과 계산

  • 인정시간 = 근무 시작~종료 − 휴게. 기본은 주간 08:00~17:00 − 점심 60분 = 8시간, 주간+야간 08:00~20:00 − 점심 60분 − 17:00~17:30 30분 = 10.5시간입니다.
  • 계획 시간 = 인정시간 − 쉬는 시간(오전 · 오후 각 10분, 합 20분). 기획자 기준 8to5 근무 = 540분 − 점심 60분 − 쉬는 시간 20분 = 460분이고, 주간+야간은 610분입니다.
  • 계획 시간 기준은 「기록된 계획 시간」(가동률 시트의 계획 시간, 일일 집계의 인정시간)과 「근무 형태 기준」 중에서 고릅니다. 기록이 없으면 근무 형태로 계산합니다.
  • 가동률 = 가동 시간 ÷ 계획 시간. 계획이 0 인 날은 계산하지 않고 빈칸으로 둡니다.
  • 휴게 분리 — 가동 · 비가동 구간이 휴게 구간과 겹치면 겹친 만큼 뺍니다. 휴게 줄은 가동 · 비가동에 넣지 않습니다.
  • 파레토 — 사유를 비가동 시간이 큰 순으로 늘어놓고 누적 비율을 그립니다. 앞의 두세 사유가 대부분이면 그 사유부터 줄이면 됩니다.
  • 근무 형태는 「근무」 칸을 먼저 보고, 비어 있으면 그날 마지막 종료가 17:30 을 넘는지로 정합니다.

사유 코드는 설비군마다 다릅니다(기획자 기준). 같은 글자라도 뜻이 달라서, 이 도구는 「설비군 + 코드」로 따로 세고 화면에는 사유 이름으로 보여 줍니다.

설비군ABCDEFGH
가공설비제관품無장비고장지그교체계획정지공정결원청소기타
용접설비제관품대기제관품無장비고장티칭수정계획정지공정결원청소기타

전체 파레토와 설비×사유 표는 이름이 같은 사유를 합칩니다. 예를 들어 「장비고장」은 가공 B 와 용접 C 를 더하고, 옆에 「가공 B · 용접 C」처럼 어느 군 코드에서 왔는지 적습니다. 코드표와 근무 형태는 「기준 설정」에서 고칠 수 있고, 이 브라우저에 저장됩니다.

기획자 설비 목록(2026-11)

기획자가 알려 준 실제 설비 이름 30대입니다(가공 10대 · 용접 20대). 「기준 설정 → 설비군 → 기획자 설비 목록 불러오기」를 누르면 한 번에 등록되고(이미 고른 이름은 그대로), 빈 양식의 범례 시트 아래에도 같은 목록이 있어 수기 일보를 옮겨 적을 때 보고 쓸 수 있습니다.

4. 확인할 것

다음을 찾아 대시보드 아래에 모읍니다. 수치가 틀어질 수 있는 기록이니 원본 일보와 대조해 주세요.

  • 같은 설비 · 같은 날에 서로 겹친 구간
  • 가동까지 적은 날에 쉬는 시간(20분)보다 긴 빈 시간
  • 그 설비군 코드표에 없는 글자(예: 가공설비에 H)
  • 소요(분) 기록과 시작~종료 계산이 다른 줄
  • 코드가 비었거나 사유 코드 표에 없는 비가동(미분류로 셉니다)
  • 날짜 · 시간을 읽지 못해 뺀 줄, 일일 집계와 작업일보의 비가동이 다른 날, 수리 이력의 총시간과 구간이 다른 줄

5. 보고서 · 엑셀

보고서는 월간 설비 운영실적 보고 형식의 인쇄용 화면입니다. 요약 문장은 규칙으로 만들고(가동률 · 상위 사유 · 목표 미달 설비 · 최저일 · 수리 이력), 그림과 표가 함께 들어갑니다. 「인쇄하기」에서 PDF 로 저장할 수도 있습니다.

AI 다듬기는 선택입니다. API 키를 넣으면 요약 문장만 보고서 문체로 다듬고 「AI 초안 — 검토 필요」로 따로 보여 줍니다. 보내기 전에 한 번 더 묻습니다.

엑셀은 요약 · 설비별 · 사유별 · 일별 · 월별 · 설비x사유 · 일자별상세 · 가동률양식 · 확인할것 · 수리이력 · 기준 시트입니다. 「가동률양식」은 회사 설비 가동률 시트와 같은 모양이라 다시 올리면 같은 값으로 읽힙니다.

6. 이번 판에서 하지 않는 것

  • 수기 일보 사진을 바로 읽기(OCR) — 엑셀 양식으로 옮겨 적은 자료만 읽습니다.
  • 근태 시트(출근 · 퇴근 · 근무시간 격자)와 월별 요약 시트 읽기 — 가동률 계산에는 쓰지 않습니다.
  • 엑셀 입력 양식의 드롭다운 목록 — 범례 시트로 대신합니다.
  • 사내 시스템(MES 등) 자동 연동 · 여러 사람이 함께 쓰는 저장소.

스캔본 읽기 (v1.3)

손으로 쓴 생산작업일보(가공설비) · 자동용접 ROBOT 가동일보 스캔본(사진 · PDF)을 스캔본 읽기에 올리고, OpenAI 또는 Anthropic 키를 넣고 외부 전송을 확인한 뒤 「읽기」를 누르면 AI 비전이 머리(설비 · 작업자 · 날짜 · 시작 · 종료), 비가동 내역(범례 A~H · 시작 · 종료 · 내역), 작업 내역/생산 현황을 JSON 으로 읽어 옵니다. 읽은 값은 원본 옆에서 고칠 수 있고, 범례 코드 · 시각 · 날짜 · 겹침을 검사해 「확인할 것」으로 올립니다. 「집계 화면으로 보내기」를 누르면 이 도구의 입력 양식(설비 · 설비군 · 작업자 · 날짜 · 근무 · 구분 · 코드 · 시작 · 종료 · 소요 · 내용)으로 바뀌어 집계 화면에 파일처럼 올라갑니다. 양식의 범례 이름으로 설비군별 집계 코드표를 다시 찾아 맞춥니다(가공 양식의 「제관품無」 → 가공 B, 용접 양식의 「장비고장」 → 용접 C). 키가 없으면 「손으로 입력」으로 같은 표를 채웁니다. AI 가 못 읽은 칸은 비워 두고 알립니다 — 지어내지 않습니다.
