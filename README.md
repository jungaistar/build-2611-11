# build-2611-11 · 설비 비가동 집계 · 가동률 보고서

생성형 AI 업무자동화 전문가과정 **2차수** 수강생 프로젝트 11 — 기획 정한결.

**바로 쓰기: https://aebonlee.github.io/build-2611-11/**

수기 작업일보를 엑셀 양식으로 옮겨 올리면 설비별 · 사유별 비가동 시간과 가동률,
비가동 사유 파레토, 일별 추이와 월간 설비 운영실적 보고서를 만듭니다.
겹친 구간 · 빠진 시간 · 소요 불일치 · 코드 없는 비가동은 「확인할 것」으로 모아 보여 줍니다.
파일은 브라우저 안에서만 처리하며 서버로 올라가지 않습니다.

| 파일 | 역할 |
|---|---|
| `js/downtime.js` | 계산 엔진(형식 판별 · 읽기 · 시간 계산 · 검사 · 집계 · 요약 문장 · 보고서 · 엑셀 시트 · 예제) — 계산은 전부 여기 |
| `js/app.js` | 화면(파일 올리기 · 기준 설정 · SVG 그래프 · 보고서 미리보기 · 내려받기) |
| `samples/` | 빈 입력 양식, 가짜로 채운 예제(입력 양식 · 작업일보 · 가동률 시트 · 수리 이력) — `node tools/make-samples.js` 로 다시 만든다 |
| `test/logic.test.js` | 계산 규칙 테스트 `node test/logic.test.js` |
| `test/smoke.browser.js` | 화면 연기 테스트(playwright) |
| `CLAUDE.md` | 작업 지시서 + 기획서 원문 |

사유 코드는 설비군마다 다릅니다(가공설비 A~G · 용접설비 A~H, 기획자 기준) — 같은 글자라도 따로 세고 화면에는 이름으로 합쳐 보여 줍니다.
가동률 기준은 1일 작업시간 − 점심 60분 − 쉬는 시간 20분(8to5 = 460분)입니다.
설비군은 설비 이름으로 판정합니다(v1.2) — 용접 라인 MAIN · BOOM · TRACK · SUB · CHASSIS · ARM · BUCKET · BLADE(N호기)나 로봇 · 용접 · 제조사 낱말이 있으면 용접, NC · MCT · 밀링 · 호리젠탈 · 머시닝이 있으면 가공, 둘 다 있으면 「확인 필요」로 사용자가 고릅니다.
「기준 설정 → 설비군 → 기획자 설비 목록(2026-11) 불러오기」로 기획자의 설비 30대를 한 번에 등록할 수 있고, 빈 양식의 범례 시트에도 같은 목록이 있습니다.

예제 데이터는 실제 사내 데이터가 아닙니다(설비 · 작업자 · 수리 이력 모두 시드 고정으로 만든 가짜 값).

## v1.3 (2026-11-04) — 스캔본 읽기

손으로 쓴 생산작업일보 · 용접 ROBOT 가동일보 스캔본(사진 · PDF)을 `scan.html` 에 올리면 AI 비전(OpenAI/Anthropic, 키 + 외부 전송 확인)이 표를 읽고, 원본 옆에서 확인 · 수정한 뒤 입력 양식으로 바꿔 집계 화면에 올립니다. 키가 없으면 같은 표를 손으로 넣습니다. 엔진 `js/scanread.js`, 화면 `js/scan.js`.
